🧱 Block Guide

Every block in Block Game Maker, explained in plain words. There are 70 blocks in 9 groups. Tap a group below to jump to it.

🧭 How it works

  1. Every object in your game (the hero, a coin, an enemy…) has its own script made of blocks.
  2. A script always starts with a yellow event block (like “When game starts” or “Every frame”). It says when the blocks below it run.
  3. Tap ＋ Add block to put a block inside. Tap ƒ next to a hole to plug a round value block or a pointy yes/no block into it.
  4. Tap ⋮ on a block to move it up or down, copy it, or delete it.
  5. Tap ▶ Play to try your game. Tap 📝 Lua if you want to write code instead.

The five kinds of block

Event block

Starts a script. Nothing can go above it.

Step block

Does one thing. Snaps into a script.

Wrapper block

Holds other blocks inside it.

Value block

Gives back a number or some words. Plugs into a round hole.

Yes/No block

Answers yes or no. Plugs into an “If” or a yes/no hole.

⚡ Events

Blocks that start a script. Every script begins with one of these.

When game starts
…
Event block

Runs one time when the game begins (and again each time the game restarts). Use it to get things ready: set a starting position, reset the score, give the object a first speed.

Example: When game starts → Set score to 0 → Go to x 40 y 200.

Show the Lua code
function start()
  -- other blocks go here
end
Every frame
…
Event block

Runs again and again, about 60 times every second, for as long as the game is running. Put things here that must keep happening: moving while a button is held, checking if you fell off the screen, updating the score text.

Example: Every frame → If button Right is down → Move right by 3.

Show the Lua code
function update(dt)
  -- other blocks go here
end
Every 1 seconds
…
Event block

Starts a timer. The blocks inside run once every N seconds, for as long as the game is running. Great for making enemies or coins appear now and then.

Example: Every 3 seconds → Make a copy of Enemy at x 600 y 250.

Show the Lua code
function start()
  every(1, function()
    -- other blocks go here
  end)
end
When I am tapped
…
Event block

Runs when the player taps (or clicks) this object on the screen.

Example: When I am tapped → Change score by 1 → Play sound coin.

Show the Lua code
function tapped()
  -- other blocks go here
end
When I touch anything ▾
…
Event block

Runs while this object overlaps the object you choose. It keeps running on every frame while they overlap, so it is best used for things that end the touching (like Delete me) or that are fine to repeat. Choose "anything" to react to every object.

  • Which object: pick one of the objects in your game (or “anything”).

Example: On a coin: When I touch Hero → Change score by 1 → Delete me.

Show the Lua code
function touching(other)
  if other.name == "Coin" then
    -- other blocks go here
  end
end
When button Left ▾ is pressed
…
Event block

Runs once at the moment the player presses the chosen on-screen button (or keyboard key). Buttons are Left, Right, Up, Down, A and B. On a computer: arrow keys or WASD, Space or Z for A, X for B.

  • Button: Left, Right, Up, Down, A, B

Example: When button A is pressed → Jump with power 12.

Show the Lua code
function pressed(button)
  if button == "Left" then
    -- other blocks go here
  end
end
When I get message go
…
Event block

Runs when any object uses "Send message" with the same word. Messages are how objects talk to each other.

Example: When I get message "boom" → Hide → Play sound hit.

Show the Lua code
function message(name)
  if name == "go" then
    -- other blocks go here
  end
end
When the screen is tapped
…
Event block

Runs when the player taps anywhere on the screen. Use the "Tap x" and "Tap y" blocks to find out where.

Example: When the screen is tapped → Go to x (Tap x) y (Tap y).

Show the Lua code
function screen_tapped(x, y)
  -- other blocks go here
end

🏃 Move

Make your object walk, jump, bounce and turn.

Move right ▾ by 5
Step block

Moves your object a few steps in a direction. If your object "hits solid things", it stops when it bumps into a solid object like a wall or platform.

  • Direction: right, left, up, down

Example: If button Left is down → Move left by 3.

Show the Lua code
move(5, 0)
Go to x 0 y 0
Step block

Jumps your object straight to a place on the screen. x is how far from the left edge, y is how far from the top edge. It ignores walls.

Example: When game starts → Go to x 40 y 200.

Show the Lua code
go_to(0, 0)
Set x to 0
Step block

Puts your object at this distance from the left edge of the screen, without changing its up/down position.

Example: If x is bigger than 640 → Set x to 0 (wrap around).

Show the Lua code
me.x = 0
Set y to 0
Step block

Puts your object at this distance from the top edge of the screen, without changing its left/right position.

Example: Set y to 0 puts the object at the very top.

Show the Lua code
me.y = 0
Set sideways speed to 0
Step block

Gives your object a sideways speed. It keeps moving by itself every frame. Positive goes right, negative goes left, 0 stops.

Example: On an enemy: When game starts → Set sideways speed to 1.5.

Show the Lua code
me.vx = 0
Set up/down speed to 0
Step block

Gives your object an up/down speed. Positive goes down, negative goes up. Objects with gravity change this speed by themselves.

Example: Set up/down speed to -10 launches the object upward.

Show the Lua code
me.vy = 0
Jump with power 12
Step block

Makes your object jump up — but only if it is standing on the ground (or on a solid object). Needs gravity turned on. Bigger power = higher jump.

Example: When button A is pressed → Jump with power 12.

Show the Lua code
jump(12)
Bounce off left & right walls ▾
Step block

If your object reached the edge of the world or bumped into a solid object, it turns around (its speed flips). Use it with "Set sideways speed" to make something that walks back and forth or a bouncing ball.

  • Which walls: left & right walls, top & bottom walls, all walls

Example: On a ball: Every frame → Bounce off all walls.

Show the Lua code
bounce("sides")
Stay inside the world
Step block

If your object is partly outside the world, push it back in. Handy so the player cannot walk off the edge.

Example: Every frame → Stay inside the world.

Show the Lua code
keep_inside()
Move toward object ▾ by 2
Step block

Moves your object a little bit toward the nearest object with that name. Use it for enemies that chase the hero.

  • Which object: pick one of the objects in your game.

Example: On a ghost: Every frame → Move toward Hero by 1.

Show the Lua code
move_toward("Coin", 2)
Turn 15 degrees
Step block

Spins your object clockwise by this many degrees (use a negative number to spin the other way). It only changes how the object looks — it does not change its hitbox.

Example: On a coin: Every frame → Turn 5 degrees.

Show the Lua code
me.angle = me.angle + 15
Turn gravity ▾ on ▾
Step block

Switches one of your object's abilities on or off while the game runs. Gravity: it falls. Solid: other objects cannot pass through it. Hits solid things: it stops when it bumps into solid objects.

  • Ability: gravity, solid, hits solid things
  • On or off: on, off

Example: When I am tapped → Turn gravity on (the object falls).

Show the Lua code
me.gravity = true

🎨 Look

Change how your object looks and what it says.

Say Hello! for 2 seconds
Step block

Shows a speech bubble above your object for a few seconds. The game keeps running while the bubble is shown.

Example: When I touch Hero → Say "Ouch!" for 1 seconds.

Show the Lua code
say("Hello!", 2)
Change look to 😀
Step block

Changes the picture of your object to a different emoji. Tap the emoji box to pick one.

Example: When I am tapped → Change look to 💥.

Show the Lua code
me.emoji = "😀"
Set color to
Step block

Changes the color of your object. This is the fill color of boxes and circles, and the letter color of text.

Example: When I touch Hero → Set color to red.

Show the Lua code
me.color = "#ff5252"
Set size to 100 %
Step block

Makes your object bigger or smaller. 100 is normal size, 50 is half size, 200 is double size. The hitbox changes too.

Example: When I touch Mushroom → Set size to 150 %.

Show the Lua code
set_size(100)
Show
Step block

Makes your object visible again. Visible objects can touch other objects and be tapped.

Example: When I get message "reveal" → Show.

Show the Lua code
me.visible = true
Hide
Step block

Makes your object invisible. A hidden object cannot be touched or tapped, but its scripts keep running.

Example: When game starts → Hide (until a message says to show it).

Show the Lua code
me.visible = false
Set my text to Score: 0
Step block

Changes the words shown on your object. Use it with a Text object to show the score. Drop a "Join" block in here to mix words and numbers.

Example: Every frame → Set my text to (Join "Score: " and score).

Show the Lua code
me.text = tostring("Score: 0")
Face right ▾
Step block

Flips the picture so your object looks to the left or to the right. Pictures start out facing right.

  • Direction: right, left

Example: If button Left is down → Face left.

Show the Lua code
face("right")
Set background color to
Step block

Changes the color of the whole game background (the sky behind everything).

Example: When I touch Door → Set background color to black.

Show the Lua code
set_background("#87ceeb")

🔊 Sound

Play short sound effects.

Play sound jump ▾
Step block

Plays a short sound effect: jump, coin, hit, win, lose or beep. The game does not wait for the sound to finish.

  • Sound: jump, coin, hit, win, lose, beep

Example: When I touch Hero → Play sound coin.

Show the Lua code
play("jump")

🔁 Control

Make decisions, repeat things, wait, and talk to other objects.

If yes/no then
…
Wrapper block

Only runs the blocks inside if the question is true. Drop a yes/no block (like "Button Left is down") into the hole.

Example: If button Left is down then Move left by 3.

Show the Lua code
if false then
  -- other blocks go here
end
If yes/no then
…
Wrapper block

Like "If", but with two parts. The top part runs when the question is true, the bottom part ("else") runs when it is not.

Example: If On the ground? then Set color to green else Set color to red.

Show the Lua code
if false then
  -- other blocks go here
else
  -- other blocks go here
end
Repeat 10 times
…
Wrapper block

Runs the blocks inside again and again, the number of times you choose, all at once (not one per frame).

Example: Repeat 5 times → Make a copy of Star at x (Random 0 to 600) y 0.

Show the Lua code
for _ = 1, 10 do
  -- other blocks go here
end
Repeat while yes/no
…
Wrapper block

Keeps running the blocks inside as long as the question is true. Make sure something inside changes the answer, or the game will stop with an "endless loop" message.

Example: Repeat while y is smaller than 300 → Change my y... (move down by 1).

Show the Lua code
while false do
  -- other blocks go here
end
After 1 seconds
…
Wrapper block

Waits a little while and then runs the blocks inside, one time. The rest of your script does not wait — it carries on straight away.

Example: When I touch Hero → After 2 seconds → Delete me.

Show the Lua code
after(1, function()
  -- other blocks go here
end)
Send message go
Step block

Shouts a word to every object in the game. Every object with a matching "When I get message" block runs its script.

Example: When I touch Hero → Send message "open".

Show the Lua code
send("go")
Stop this script
Step block

Stops the current script right here. Blocks after it do not run this time. Scripts start again on their next event.

Example: If score is 0 → Stop this script.

Show the Lua code
do return end
Delete me
Step block

Removes this object from the game for good (until the game restarts). Use it for collected coins, used-up bullets or defeated enemies.

Example: When I touch Hero → Delete me.

Show the Lua code
destroy()
Make a copy of object ▾ at x 0 y 0
Step block

Creates a brand-new copy of an object you made, at the place you choose. The copy runs its own "When game starts" script right away.

  • Which object: pick one of the objects in your game.

Example: Every 2 seconds → Make a copy of Coin at x (Random 20 to 600) y 0.

Show the Lua code
spawn("Coin", 0, 0)

📦 Variables

Boxes that remember numbers or words, like a score.

Set variable ▾ to 0
Step block

Puts a value into a variable (a labeled box that remembers things). Every object can see the same variables. Make new ones with "＋ New variable".

  • Which variable: pick one of your variables, or make a new one.

Example: When game starts → Set score to 0.

Show the Lua code
vars.score = 0
Change variable ▾ by 1
Step block

Adds a number to a variable. Use a negative number to subtract.

  • Which variable: pick one of your variables, or make a new one.

Example: When I touch Hero → Change score by 1.

Show the Lua code
vars.score = vars.score + 1
variable ▾
Value block

The current value of a variable. Drop it into any block that has a round or white hole. A variable you never set counts as 0.

  • Which variable: pick one of your variables, or make a new one.

Example: Set my text to (Join "Score: " and (score)).

Show the Lua code
vars.score
Save 0 as highscore
Step block

Stores a value on the device so it is still there next time the game is played. Good for a high score.

Example: When game over → Save score as "highscore".

Show the Lua code
save("highscore", 0)
Saved value highscore or 0 if none
Value block

Reads back a value you stored with "Save". If nothing was saved yet, you get the backup value you typed in.

Example: When game starts → Set best to (Saved value "highscore" or 0 if none).

Show the Lua code
saved("highscore", 0)

🧮 Math

Do sums, pick random numbers, compare things and join words.

0 + ▾ 0
Value block

Does a sum with two numbers: add, subtract, multiply, divide, or "remainder" (what is left over after dividing). You can put other blocks in the holes.

  • Operation: +, −, ×, ÷, remainder

Example: (score) × 10 gives ten points for each coin.

Show the Lua code
(0 + 0)
Random number from 1 to 10
Value block

Picks a whole number at random between the two numbers (both can be picked). Different every time.

Example: Go to x (Random 0 to 600) y 0.

Show the Lua code
random(1, 10)
round ▾ of 0
Value block

Changes one number: round it to the nearest whole number, round down, round up, remove the minus sign, or take the square root.

  • What to do: round, round down, round up, positive of, square root of

Example: round of 3.7 is 4. positive of -5 is 5.

Show the Lua code
math.floor(0 + 0.5)
0 = ▾ 0
Yes/No block

Compares two values and answers yes (true) or no (false). Use it in the hole of an "If" block.

  • Operation: =, ≠, <, >, ≤, ≥

Example: If (score) = 10 then You win.

Show the Lua code
(0 == 0)
yes/no and ▾ yes/no
Yes/No block

Joins two yes/no questions. "and" is yes only when both are yes. "or" is yes when at least one is yes.

  • Operation: and, or

Example: If (Button Left is down) or (Button A is down) ...

Show the Lua code
(false and false)
not yes/no
Yes/No block

Flips a yes/no answer: yes becomes no, and no becomes yes.

Example: If not (On the ground?) then Say "Wheee!".

Show the Lua code
(not false)
true ▾
Yes/No block

A fixed yes (true) or no (false).

  • Value: true, false

Example: Use true to make an "If" that always runs.

Show the Lua code
true
Join Score: and …
Value block

Sticks two pieces together into one piece of text. Numbers are turned into text, so you can put a variable in one of the holes.

Example: Join "Score: " and (score) makes Score: 3.

Show the Lua code
(tostring("Score: ") .. tostring(""))

👀 Sensing

Ask questions about the game: what is pressed, what is touching, where things are.

Button Left ▾ is down
Yes/No block

Yes while the player is holding that button down. Use it inside "Every frame" for smooth movement.

  • Button: Left, Right, Up, Down, A, B

Example: Every frame → If Button Right is down → Move right by 3.

Show the Lua code
button("Left")
Touching anything ▾ ?
Yes/No block

Yes when this object overlaps an object with that name right now. Choose "anything" to check every object.

  • Which object: pick one of the objects in your game (or “anything”).

Example: If Touching Water? then Game over.

Show the Lua code
is_touching("Coin")
On the ground?
Yes/No block

Yes when this object is standing on something solid. Needs gravity turned on.

Example: If On the ground? then Set color to green.

Show the Lua code
me.on_ground
My x ▾
Value block

One fact about this object: where it is (x, y), how big it is, how fast it moves, or its text.

  • What fact: x, y, width, height, sideways speed, up/down speed, text

Example: If (My y) > 400 then Game over (fell off the world).

Show the Lua code
me.x
x ▾ of object ▾
Value block

One fact about another object (the first one with that name): its position, size, speed or text. If it does not exist you get 0.

  • What fact: x, y, width, height, sideways speed, up/down speed, text
  • Which object: pick one of the objects in your game.

Example: Go to x (x of Hero) y (y of Hero).

Show the Lua code
prop_of("Coin", "x")
Distance to object ▾
Value block

How far away the nearest object with that name is, measured from middle to middle. If there is none, you get a very big number.

  • Which object: pick one of the objects in your game.

Example: If (Distance to Hero) < 100 then Say "I see you!".

Show the Lua code
distance_to("Coin")
How many object ▾ exist
Value block

Counts how many objects with that name are still in the game. Perfect for "collect all the coins".

  • Which object: pick one of the objects in your game.

Example: If (How many Coin exist) = 0 then You win.

Show the Lua code
count("Coin")
Screen width ▾
Value block

The width or height of the visible game screen, in game pixels.

  • Which size: width, height

Example: If (My y) > (Screen height) then Game over.

Show the Lua code
screen.width
Tap x ▾
Value block

Where the player last tapped the screen. x counts from the left, y from the top.

  • Which one: x, y

Example: When the screen is tapped → Go to x (Tap x) y (Tap y).

Show the Lua code
tap.x
Seconds since start
Value block

How many seconds have passed since the game started (or restarted).

Example: Set my text to (Join "Time: " and (round of (Seconds since start))).

Show the Lua code
game_time()

🎮 Game

Win, lose, restart, camera, gravity and notes.

Game over: Try again!
Step block

Ends the game with a "game over" screen and your message. Tapping the screen starts the game again.

Example: When I touch Spike → Play sound lose → Game over: "Ouch!".

Show the Lua code
game_over("Try again!")
You win: Great job!
Step block

Ends the game with a "you win" screen and your message. Tapping the screen plays again.

Example: When I touch Flag → You win: "You made it!".

Show the Lua code
win("Great job!")
Restart the game
Step block

Starts the whole game over from the beginning: all objects go back to where you placed them and variables go back to 0.

Example: When button B is pressed → Restart the game.

Show the Lua code
restart()
Camera follows me
Step block

Makes the screen scroll to follow this object. Needs a world that is bigger than the screen (see Game settings).

Example: On the hero: When game starts → Camera follows me.

Show the Lua code
camera_follow()
Set gravity to 0.6
Step block

Changes how strongly gravity pulls objects that have gravity turned on. 0.6 is normal. 0.2 feels like the moon. 0 means floating.

Example: When I touch Moon → Set gravity to 0.2.

Show the Lua code
set_gravity(0.6)
Set x ▾ of object ▾ to 0
Step block

Changes one fact about another object (the first one with that name), like moving it or changing its text.

  • What fact: x, y, width, height, sideways speed, up/down speed, text
  • Which object: pick one of the objects in your game.

Example: Set text of ScoreBoard to (score).

Show the Lua code
set_prop_of("Coin", "x", 0)
Note: my note
Step block

A reminder for yourself. It does nothing when the game runs. In the Lua version it becomes a comment.

Example: Note: "this part makes the hero jump".

Show the Lua code
-- my note
Show hi in the log
Step block

Writes a value into the log panel under the play screen. Handy for finding out what is going on inside your game.

Example: Show (My y) in the log.

Show the Lua code
log("hi")

📝 Lua guide

Prefer typing code? Switch any object to Lua mode. Every block above turns into one of these functions. The 🧩→📝 button turns your blocks into Lua so you can learn from them.

Moving

move(dx, dy)Move by dx sideways and dy down. Stops at solid things if “Hits solid things” is on.
go_to(x, y)Jump to a place.
jump(power)Jump up (only on the ground).
bounce(mode)Turn around at walls. mode is "sides", "top" or "all".
keep_inside()Push back into the world.
move_toward(name, amount)Step toward the nearest object with that name.
set_size(percent)Change size (100 is normal).
face("left" or "right")Flip the picture.

Looks & sound

say(text, seconds)Speech bubble.
play(name)Sound: "jump", "coin", "hit", "win", "lose", "beep".
set_background(color)Change the sky color, like "#000000".

Time & other objects

after(seconds, fn)Run fn once later.
every(seconds, fn)Run fn again and again.
send(text)Tell all objects. They get it in message(name).
spawn(name, x, y)Make a copy of an object. Returns the new object.
destroy()Delete this object.
get(name)The first object with that name (or nil).
count(name)How many objects have that name.
is_touching(name)true if touching an object with that name (nil = anything).
distance_to(name)Distance to the nearest one.
prop_of(name, property)A property of another object.
set_prop_of(name, property, value)Change a property of another object.

Game

game_over(text)Game over screen.
win(text)You win screen.
restart()Start again.
camera_follow()Scroll the screen to follow me.
set_gravity(number)Change gravity.
button(name)true while that button is held: "Left", "Right", "Up", "Down", "A", "B".
random(a, b)Random whole number from a to b.
game_time()Seconds since the game started.
save(key, value)Remember a value on this device.
saved(key, backup)Read a remembered value.
log(value)Write to the log under the play screen.

Special values

meThis object. Properties: x, y, w, h, vx, vy, angle, flip, visible, solid, gravity, collide, fixed, shape, emoji, color, text, on_ground.
varsYour variables: vars.score. A variable you never set is 0.
screen.width, screen.heightSize of the screen.
tap.x, tap.yWhere the player last tapped.

Your functions (the game calls them)

function start()When the game starts.
function update(dt)Every frame. dt is the time since last frame.
function tapped()When this object is tapped.
function touching(other)While touching another object. other.name tells you who.
function pressed(button)When a button is pressed.
function message(name)When a message arrives.
function screen_tapped(x, y)When the screen is tapped.

Lua basics

local x = 5Make a variable that only this script can see.
if a then ... elseif b then ... else ... endDecide.
for i = 1, 10 do ... endCount.
while cond do ... endRepeat while true.
function name(a, b) ... endMake your own function.
{1, 2, 3} and {x = 1}Lists and records (tables). #list is the length.
a .. bJoin text.
-- noteA comment.
math.floor, math.sqrt, math.abs, math.max, math.min, math.sin …Math helpers.
string.format("%d", n), ("x"):upper() …Text helpers.
table.insert, table.remove, ipairs, pairsList helpers.

Ready-made objects (with blocks already inside) and starter games. Add objects with “＋ Add object” in the Scene tab.

Objects you can add

🐱
Hero (jumper)

Walks left and right, jumps with button A, falls with gravity. Camera follows. Game over if it falls off the world.

Hero (top-down)

Walks in four directions, no gravity. Great for mazes and chase games.

🧺
Catcher basket

Slides left and right along the bottom. Catches things that fall.

🟩

A solid green block. Other objects can stand on it and cannot walk through it.

🪙
Coin

👻

🔺

🚩

⭐

⚽
Bouncy ball

🔢

🔄

🔤

⬜
